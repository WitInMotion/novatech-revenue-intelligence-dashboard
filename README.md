 NovaTech Revenue Intelligence Dashboard

This project creates a revenue intelligence dashboard for NovaTech using Amazon Quick in the Udacity Vocareum workspace.

 Contents

- `executive_report_outline.md` - executive report structure and findings
- `verification_log_draft.md` - knowledge-base verification log
- `q_exploration_log_complete.md` - Q questions, answers, cross-checks, and insights
- `business_insight_guide.md` - guidance for turning findings into recommendations
- `screenshots/` - screenshots from Amazon Quick
- `dashboard_export.pdf` - optional PDF export of the completed dashboard

 Data sources

- `novatech_crm_deals.csv` - sales pipeline and deal outcomes
- `novatech_marketing_campaigns.csv` - campaign performance
- `novatech_support_tickets.csv` - customer-support activity
- `NovaTech Unified Account...` - unified Amazon Quick dataset used for the dashboard

 Dashboard views

1. Marketing Funnel
2. Sales Pipeline
3. Customer Health

The dashboard connects the datasets using `account_id` and includes filters for the main business dimensions.

 Important note

The live dashboard remains in the Amazon Quick/Vocareum environment. This repository contains the report, logs, screenshots, and optional PDF export that document the completed work. No AWS credentials or private access keys should be committed.
